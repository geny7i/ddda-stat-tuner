# 育成経路とステータス計算

`src/domain/` は React や状態管理に依存しない計算モデルです。画面からは `src/domain/index.ts` を入口として利用します。

- レベル帯は Lv1、Lv2～10、Lv11～100、Lv101～200 の 4 つです。各帯の配列は、その帯で選んだ職業をレベル順に保持します。
- Lv1～10 では基本職 3 種のみ、Lv11 以降では全 9 職を選択できます。配列は帯のレベル数まで持てます。編集中の短い配列や空配列も有効です。
- ステータスは、経路に含まれる各レベルの職業成長値を足し、体格に応じた ST 補正を加えます。体格 `ss`、`s`、`m`、`l`、`ll` の補正はそれぞれ 0、20、40、60、80 です。
- 職業比較のスコアでは HP と ST を 10 分の 1、他の項目をそのまま加算します。注目項目が空なら全職業のスコアは 0 で、入力順を保ちます。
- `validateCharacterInfo` は未知の体格・職業、選択できない帯の職業、帯の上限を超える経路、欠けた帯を拒否します。計算前にも同じ検証を行います。

計算・並べ替えは入力を変更しません。復元 URL の解析や画面から受け取ったデータは、このモデルの検証を通してから利用します。
