# Phase 6 ポーンの倍数調整の到達性

## 結論

リポジトリの成長表を使い、ポーンの6職業だけで全6能力を倍数にできるか、剰余状態を全列挙した。全200Lv入力済みで、Phase 5と同じくLv1〜10を維持する前提。

| 目標     | 成立条件                      | Lv11〜100の変更上限 | Lv101〜200の変更上限 | 合計 |
| -------- | ----------------------------- | ------------------- | -------------------- | ---- |
| 5の倍数  | すべてのポーン経路            | 6Lv                 | 6Lv                  | 12Lv |
| 10の倍数 | Lv2〜10のメイジ成長回数が奇数 | 9Lv                 | 14Lv                 | 23Lv |

全5体格で同じ結論になる。前半の変更先からメイジを除外しても成立し、既存のメイジを増やす必要はない。この上限は解の存在を保証する十分な上限であり、経路ごとの最小変更数や、全体として最も小さい保証上限を示すものではない。

Lv2〜10のメイジ成長回数が偶数の場合、10の倍数への調整は不可能。Lv11〜200をすべて変更しても解決しない。たとえばLv1〜200がすべてファイターの経路は、この条件に該当する。

## 10の倍数にできない理由

攻撃・魔攻・防御・魔防の合計をCとする。

- Lv1のCは初期3職のいずれも280で偶数。
- Lv2〜10の1LvあたりのCはファイター／ストライダーが11、メイジが12。
- Lv11〜100のポーン6職の1LvあたりのCは11または13で、すべて奇数。90Lv分の合計は必ず偶数。
- Lv101〜200の1LvあたりのCは全職4で、100Lv分は400。
- 体格補正はSTのみで、Cには影響しない。

Lv2〜10のメイジ回数をkとすると、最終Cの偶奇は `(1 + k) mod 2` になる。4能力がすべて10の倍数ならCは偶数なので、kが奇数であることが必要。前半・後半の到達性を合わせると、この条件は十分条件でもある。

5の倍数では奇数の合計も許されるため、この制約はない。

## 前半の到達性

ポーンの全成長区間のSTは5の倍数で、初期値500と全体格補正も5の倍数。したがってPhase 5の前半状態にある `ST mod 5` は常に0。

前半は `((HP - ST) mod m, C mod m)` の2成分を調べればよい。後半のHP/STは5の倍数かつ合計20なので、前半調整後にこの2成分を0にすれば、後半調整で必要な保存条件を満たす。

変更先をファイター・ストライダー・ウォリアー・レンジャー・ソーサラーの5職に制限して全列挙した結果：

- m=5：6Lv分で全25状態に到達。5Lv分では不足する。
- m=10：9Lv分で、Cが奇数の全50状態に到達。8Lv分では不足する。

任意の前半6Lvまたは9Lvを再割り当てする。m=5では全状態を作れる。m=10では、調整前の最終Cが偶数なら、取り除いた9Lv分のCが奇数なので、必要な置き換え先のCも奇数になる。よって全50状態で十分である。

元の職業にメイジが含まれていても、前半成長のCが奇数、STが5の倍数という条件は共通なので、この証明はそのまま適用できる。

## 後半の到達性

6能力すべての剰余をそのまま全列挙し、圧縮した状態から制約を見落とさないように検証した。

- m=5：6Lv分で保存条件を満たす全125状態に到達。5Lv分では不足する。
- m=10：14Lv分で保存条件を満たす全2,000状態に到達。13Lv分では不足する。現行上限の12Lv分では1,940状態にとどまる。

保存条件は、HP/STが5の倍数、HP+STが20×対象Lv数、Cが4×対象Lv数になること。任意の後半6Lvまたは14Lvを取り除き、前半調整後の能力を打ち消す剰余になるよう再割り当てすれば、全6能力を指定倍数にできる。

この全状態被覆の検証は、固定した任意のLv枠を再割り当てする場合の保証。12Lv分の状態が不足することだけで、100Lvの中から変更箇所を選ぶ探索にも必ず12Lv超が必要な経路があるとまでは主張しない。

## 実装への反映事項

PR 02で到達性テストとポーン用探索を追加した。探索候補・能力評価用の最大値は種別の職業制限に従い、変更上限は種別と倍数で切り替える。画面からの種別切り替えと共有・復元の公開はPR 03で行う。

- 探索候補をポーンの6職へ制限し、前半のメイジ追加禁止を維持する。
- 5倍数は前半6／後半6Lv、10倍数は前半9／後半14Lv以内で探索する。覚者は前半14／後半12Lvを維持する。
- 共通の実行条件判定 `getRoundingEligibility` を用意し、未完成経路では偶奇にかかわらず残りLv数を返す。
- 10倍数が不可能な完成経路では、探索前に `impossible`、理由 `pawn-mage-parity`、メイジ回数を返す。既存の結果表示側もこの結果を扱い、再試行エラーと区別する。実行前のボタン無効化はPR 03で接続する。
- Lv1〜10は引き続き維持する。全経路で10倍数を保証する仕様変更は今回行わない。

到達性の保証は能力低下やスコア低下の小ささを保証しない。実探索の復元・変更上限・職業制限と、代表例の評価品質は以下のテストで別途検証する。

## 再現方法

PR 02に到達性テストを含めており、以下のコマンドで再現できる。

`src/domain/pawnRoundingReachability.test.ts` で前半・後半の全状態被覆と、その直前のLv数で被覆が不足することを検証する。初期3職、Lv2〜10の全55配分、全5体格の825通りについても偶奇条件を確認する。成長値の加算は順序に依存しないため、同じ職業回数の並べ替えは同一結果になる。

```sh
npm run test -- src/domain/pawnRoundingReachability.test.ts src/domain/roundingReachability.test.ts
```

検証結果：2ファイル、7テスト成功。

## 実探索と品質の検証

`pawnRoundingAdjustment.test.ts` では、全初期3職×ポーン6職への偏った経路×全5体格で、5倍数と成立条件を満たす10倍数の両方を検証する。これに加えてLv2〜10のメイジ回数0〜9、固定シードの混在20経路、未完成経路、丸め済み経路、前半条件を満たす経路を扱う。

成功結果を成長表から再計算し、全6能力の倍数条件、帯ごとの変更上限、禁止職業の不在、Lv1〜10の維持、前半メイジ非増加、元入力の不変性、決定性を検証する。偶数回では通常の不可能結果が返り、初期職メイジを回数に含めないことも確認する。

```sh
npm run test -- src/domain/pawnRoundingAdjustment.test.ts src/domain/pawnRoundingReachability.test.ts src/domain/roundingAdjustment.test.ts src/domain/roundingReachability.test.ts
ROUNDING_BENCH=1 npm run test -- src/domain/roundingAdjustment.bench.test.ts --reporter=verbose --silent=false
```
