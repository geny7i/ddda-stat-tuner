# v1.1.0 リリースノート

リリース予定の変更内容。v1.0.0 から現時点の main（`fcd2a60`）までの差分を対象とします。

## 育成経路の操作改善

- 配置済みの職業カードに「+1Lv」を追加しました。同じ職業をそのレベル帯へ1Lvずつ追加できます。レベル帯の上限に達するとボタンは無効になります。
- 「1Lv削除」の表記を「-1Lv」に変更しました。
- 職業カードの操作ボタンを「+1Lv」「-1Lv」「入替対象に指定」「1Lv入替」の順に並べました。

## スコア表示の改善

- 「職業と成長値」のカードに、スコアを「注目ステータスのスコア / 全ステータスのスコア」の形式で表示するようにしました。
- 注目するステータスを絞り込んでも、全6項目のスコアを同時に確認できます。たとえばLv11〜100のウォリアーで物理攻撃だけに注目すると、`5 / 16` と表示します。
- 全項目のチェックを外すと、注目ステータスのスコアは0になります。全ステータスのスコアは引き続き表示され、職業の並び順は注目項目のスコアに従います。

## 職業アイコンの更新

- 全9職業のアイコンを差し替えました。

## 使い方の更新

- 配置済み職業の「+1Lv」「-1Lv」による操作説明を追加しました。
- スコアのHP/ST係数について、おおよそ他項目の上昇幅と近くなるように定めたことを説明する文面へ更新しました。
- 育成計画の画面例と、その説明文を本文から削除しました。
