## 育成計画の使い方

覚者またはポーンの育成経路を組み立て、職業と体格からステータスを計算するツールです。装備・スキルによる補正は含みません。入力途中でも、その時点のステータスを確認できます。

**キャラクターと体格を選ぶ**

「キャラクター」で覚者／ポーンを選びます。入力がある状態で種別を切り替えると、確認後にLv1を含むすべての職業入力をリセットします。体格と注目するステータスは維持されます。キャンセルすれば計画は変わりません。

Lv1とLv2〜10ではファイター・ストライダー・メイジを選べます。Lv11以降は覚者が全9職、ポーンが基本3職とウォリアー・レンジャー・ソーサラーを選べます。ポーンではアサシン・マジックアーチャー・ミスティックナイトを使えません。

体格はSS・S・M・L・LLから選びます。体格による補正はSTに加算されます。

**レベル帯を選び、職業を追加する**

1. Lv1、Lv2〜10、Lv11〜100、Lv101〜200から編集する帯を選びます。ボタンには選択済みの職業とLv数が表示されます。
2. 職業と成長値の一覧にある **×1・×10・×100** を育成経路へドラッグして追加します。残りLv数を超える数を指定した場合は、残りLv分だけ追加します。
3. ドラッグを使わない場合は、×のボタンを選んでから **「選択を追加」** を押します。追加元の選択は選び直すまで維持されます。

![育成計画で職業を追加し、成長値と現在のステータスを確認する画面例](./images/editor-example.png)

画面例ではLv11〜100にファイターを10Lv追加しています。職業カードで成長値を比較し、育成経路の入力に応じた結果を上部の「現在のステータス」で確認できます。

**職業を入れ替える・削除する**

- 配置済みの職業を別の職業へドラッグすると、1Lv分を入れ替えます。
- ボタンで操作する場合は、配置済み職業の **「入替対象に指定」** を選び、変更先の職業で **「1Lv入替」** を押します。元の職業が残っている間は指定を維持し、続けて入れ替えられます。
- **「1Lv削除」** で1Lv減らせます。職業カード右上の **×** で、その帯の該当職業をすべて削除できます。

**成長値を比較する**

職業一覧の `hp`・`st`・`atk`・`matk`・`def`・`mdef` は、それぞれHP・ST・物理攻撃・魔法攻撃・物理防御・魔法防御です。Lv1では初期値、それ以降では1Lvあたりの成長値を表示します。

「注目するステータス」を選ぶと、選んだ項目のスコアが高い職業から並びます。計算式は[スコアについて](#help-スコアについて)を参照してください。

**自動調整を使う**

「自動調整」で種類を選び、**「自動調整を実行」** を押します。

- 能力特化は、未選択Lvだけをその能力の成長値が最大の職業で埋めます。すでに選んだ職業は変更しません。
- 5または10の倍数への調整は、全200Lvを入力してから実行できます。Lv1〜10を維持し、実際の職業を入れ替えて全6能力を指定倍数にします。変更前後の能力・スコアと変更Lv数を確認できます。
- ポーンの10倍数には追加の成立条件があります。詳しくは[倍数調整の説明](#help-ステータスの510の倍数への調整について)を参照してください。

探索中に種別・職業入力・体格を変更すると探索を中断し、古い結果を適用しません。入力を変えると以前の調整結果の表示も解除されます。

**計画を共有する・復元する**

「共有 URL をコピー」で種別・体格・育成経路を含むURLをコピーできます。そのURLを開くと計画を復元します。復元時は種別切り替えのリセット確認を挟まず、保存された経路をそのまま表示します。種別を含まない旧形式のコードは覚者として復元します。

画面を移動して戻っても編集中の計画は保持されますが、再読み込みやブラウザー終了後の自動保存はありません。後で使いたい計画は共有URLを保存してください。

## 詳細仕様

### スコアについて

全項目を対象にしたスコアは次の加重和です。

```text
score = HP / 10 + ST / 10 + 物理攻撃 + 魔法攻撃 + 物理防御 + 魔法防御
```

職業カードでは、現在のレベル帯の初期値または1Lvあたりの成長値にこの式を適用します。「注目するステータス」で選んだ項目だけを合計し、全項目を外すとスコアは0になります。倍数調整の前後スコアと探索の評価では常に全6能力を使い、注目項目の選択には連動しません。

HPとSTは他の4能力より数値の尺度が大きいため、10分の1に換算して合計する、と解釈できます。この式ではHPまたはSTの10点と、攻撃・防御の1点を同じ重みとして扱います。たとえばHPが30増えても、物理攻撃が3増えても、全項目スコアは3増えます。

係数は比較のための経験的な設定です。元の実装で10:1を選んだ厳密な理由は確認できていません。ゲーム内のダメージ式や、すべてのプレイスタイルに共通する強さを表すものではないので、重視する能力の成長値も合わせて確認してください。

### ステータスの5,10の倍数への調整について

**倍数条件を合同式で表す**

完成した能力値を `S`、1Lvの職業変更による成長値の差を `Δ`、目標倍数を `m = 5 または 10` とします。全6能力について、次の条件を満たす変更を探します。

```text
S + ΣΔ ≡ 0 (mod m)
```

つまり、mで割った余り（剰余）を0にします。表示上の端数を切り捨てる操作ではなく、育成経路を変更して計算結果を倍数にする操作です。

**成長値の性質を使って2段階に分ける**

Lv1〜10は固定し、Lv11〜100を前半、Lv101〜200を後半として調整します。後半の1Lvあたりの成長値には、全職で次の性質があります。

- HPとSTはそれぞれ5の倍数で、HP + ST = 20。
- 物理攻撃 + 魔法攻撃 + 物理防御 + 魔法防御 = 4。

4能力の合計を `C` とすると、後半100Lvの職業を入れ替えてもHP + STとCの合計値は変わりません。そのため、最初に前半の職業を変更して、後半で解ける条件を整えます。

前半の探索では次の3つの剰余を管理し、すべて0にします。

```text
((HP − ST) mod m, ST mod 5, C mod m)
```

ここでHP・ST・Cは、その時点の全200Lv分と体格を含む計算値です。10倍数では、HPとSTの剰余がともに0またはともに5、かつCが10の倍数になるよう整えます。5倍数ではHP・STとCがそれぞれ5の倍数になるよう整えます。

続いて後半の職業を変更し、各能力の剰余を0にします。HPの剰余と物理攻撃・魔法攻撃・物理防御の剰余が決まれば、STと魔法防御の剰余は前述の合計の制約から決まります。

実装の状態数は、5倍数では前半・後半各125、10倍数では前半500・後半2,000です。ポーンではSTが常に5の倍数になるなどの制約があるため、実際に到達する状態はこの一部になります。

**動的計画法で職業変更を探す**

各区間の元のLv枠を1つずつ処理し、「職業を維持する」「選択可能な別の職業へ変える」を試します。同じ剰余状態に到達した候補のうち、評価の良いものと、その経路の復元情報を保存します。これにより全経路を列挙せずに条件を満たす変更を探せます。候補数で探索を打ち切る方式ではありません。

前半ではメイジへの新たな変更を候補から除外します。もともとメイジだったLvを維持することはできます。

**強みとスコアの低下を抑える評価**

調整前の能力を `before_i`、その能力の個別の到達可能最大値を `max_i` とし、1変更に次の損失を付けます。最大値は種別の職業制限と体格から計算します。全能力の最大値を同時に達成できるという意味ではありません。

```text
能力損失 = Σ max(0, −Δi) × before_i / max_i²
スコア損失 = 0.25 × max(0, −score(Δ)) / score(before)
評価 = 各変更の能力損失とスコア損失の合計 + 変更ペナルティ × 変更Lv数
```

能力損失は、低下率に `(before_i / max_i)²` を掛けたものです。HP/STと他の能力の尺度をそろえ、最大値に近い能力の低下を重く評価します。

まず1変更あたり0.0002のペナルティで探索します。区間の変更上限を超えた場合は0.002で再探索し、それでも超える場合は変更数を最優先、損失を次優先にして探索します。各区間で上限内の解が存在することを成長表の剰余状態の全列挙で検証しており、最後の変更数優先探索により上限内の解を得られます。

**成立条件と変更上限**

全200Lvの入力が必要です。Lv1〜10は変更しません。

| 種別・目標      | 追加の成立条件                | Lv11〜100 | Lv101〜200 | 合計変更上限 |
| --------------- | ----------------------------- | --------- | ---------- | ------------ |
| 覚者・5／10倍数 | なし                          | 14Lv      | 12Lv       | 26Lv         |
| ポーン・5倍数   | なし                          | 6Lv       | 6Lv        | 12Lv         |
| ポーン・10倍数  | Lv2〜10のメイジ成長回数が奇数 | 9Lv       | 14Lv       | 23Lv         |

ポーンの10倍数条件はCの偶奇で説明できます。Lv1のCは初期3職のいずれも偶数です。Lv2〜10ではメイジの1LvあたりのCが12、ファイターとストライダーは11なので、メイジの成長回数をkとすると、この9Lv分の合計の偶奇は `(1 + k) mod 2` です。

Lv11〜100のポーン6職は1LvあたりのCがすべて奇数で、90Lv分の合計は偶数。後半は100Lv × 4 = 400で偶数。体格補正はSTだけなので、最終Cの偶奇も `(1 + k) mod 2` になります。

4能力がすべて10の倍数ならCは偶数であり、kが奇数である必要があります。現行成長表の到達性検証により、この条件は十分条件でもあります。**Lv1の初期職業のメイジはkに含めません。** kが偶数なら、Lv11以降をすべて変えても10倍数にできません。5倍数ではこの偶奇条件はありません。

**保証すること・評価の限界**

現行成長表と職業制限のもとで、成立条件を満たす入力から、上記の上限内で全6能力を指定倍数にします。すでに指定倍数なら変更しません。前半の剰余条件を満たす経路では前半を維持し、後半だけを調整します。

最高スコア、全体の最小変更数、能力の完全維持は保証しません。各変更の損失を加算する評価なので、変更による増減の相殺や、前半の別候補で後半が改善する可能性まで含めた全体最適化ではありません。
