# DDDA Stat Tuner

Dragon's Dogma: Dark Arisen の育成経路を組み立て、ステータスを確認するブラウザーアプリです。バックエンドを使わない静的 SPA として開発しています。

現在は育成経路の編集、ステータス表示、職業比較チャート、共有 URL による復元、免責事項まで実装しています。残る全体検証と整理は [Phase 1 リメイク計画](docs/phase1-remake-plan.md) に沿って進めます。

職業・レベル帯・成長値とステータス計算のモデルは追加済みです。計算ルールは [育成経路とステータス計算](docs/domain-model.md) を参照してください。

トップ画面ではレベル帯を選び、職業カードの ×1/×10/×100 をレベル帯へドラッグして追加できます。配置済みの職業を別の職業カードへドラッグすると 1 件変更します。各ボタンをクリックして選択し、画面内の追加・変更・削除ボタンを使うこともできます。Space と矢印キーでもドラッグでき、Escape で中止できます。狭い画面では職業一覧やページをスクロールして操作します。

現在のステータスは育成経路と体格の変更に合わせて更新されます。編集中のレベル帯では職業ごとの 1 レベル分の成長値を比較できます。「注目するステータス」のチェックを切り替えると、選んだ項目のスコア順に職業を並べ替えます。HP と ST は 10 分の 1、その他はそのままスコアへ加算します。

チャート画面では、トップ画面と同じ育成経路、レベル帯、注目するステータスを使い、職業ごとのスコアを棒グラフと表で比較できます。ナビゲーションで画面を移動しても編集中の状態は保たれます。

「共有 URL をコピー」を押すと、現在の育成経路と体格を含む URL をクリップボードへコピーします。`#/restore?c=...` の URL を開くと同じ内容を復元します。既存の `#restore?c=...` 形式にも対応します。不正なコードでは内容を変更せず、エラーと育成計画へ戻るリンクを表示します。

開発サーバーの `#/dnd-trial` には共通編集部品の試運転画面も残しています。採用判断と残る確認事項は [Phase 1 リメイク計画](docs/phase1-remake-plan.md#pr-03-ドラッグ操作ライブラリの試運転と採否) に記録しています。

## 必要な環境

- Node.js 24.21.0（`.tool-versions` に固定）
- npm 11

## 開発

```sh
npm ci
npm run dev
```

Vite が表示する URL を開いてください。画面の経路にはハッシュ形式（`#/chart` など）を使用します。

## 確認コマンド

```sh
npm run check       # 型検査、lint、整形検査、単体テスト、ビルド
npm run test:e2e    # ブラウザーテスト
```

ブラウザーテストの初回実行前に `npx playwright install chromium` で Chromium を用意してください。

## 静的ファイルの生成

```sh
npm run build
npm run preview
```

生成物は `dist/` です。公開先がサブパスの場合は、ビルド時に末尾の `/` を含む `APP_BASE_PATH` を設定します。例: `APP_BASE_PATH=/stat-tuner/ npm run build`。公開先では、そのパスで `index.html` とアセットを配信してください。

共有 URL は現在開いている配置先を基準に作成するため、公開先のホスト名をコードへ固定していません。公開先の変更時には既存の共有 URL の到達先も確認します。
