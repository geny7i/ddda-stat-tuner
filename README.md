# DDDA Stat Tuner

Dragon's Dogma: Dark Arisen の育成経路を組み立て、ステータスを確認するブラウザーアプリです。

## 現在の状態

リメイクの準備段階です。アプリ本体と開発コマンドは、実装用の最初の PR で追加します。

## 開発方針

- バックエンドを使わない静的な SPA として公開します。
- React、TypeScript、Vite を採用します。Node.js は実装時点の LTS 系を使用します。
- 既存の共有 URL を利用できるよう、ハッシュ形式の経路と復元コードの互換性を保ちます。
- 計算ロジック、画面操作、共有 URL をそれぞれテストします。

実装順序と PR ごとの完了条件は [Phase 1 リメイク計画](docs/phase1-remake-plan.md) を参照してください。
