# DDDA Stat Tuner

Dragon's Dogma: Dark Arisen の育成経路を組み立て、ステータスを確認するブラウザーアプリです。バックエンドを使わない静的 SPA として開発しています。

現在は画面遷移、計算モデル、育成経路の編集画面まで実装しています。ステータス表示と共有機能は [Phase 1 リメイク計画](docs/phase1-remake-plan.md) に沿って追加します。

職業・レベル帯・成長値とステータス計算のモデルは追加済みです。計算ルールは [育成経路とステータス計算](docs/domain-model.md) を参照してください。計算結果の表示は後続の PR で行います。

トップ画面ではレベル帯を選び、職業カードの ×1/×10/×100 をレベル帯へドラッグして追加できます。配置済みの職業を別の職業カードへドラッグすると 1 件変更します。各ボタンをクリックして選択し、画面内の追加・変更・削除ボタンを使うこともできます。Space と矢印キーでもドラッグでき、Escape で中止できます。狭い画面では職業一覧やページをスクロールして操作します。編集状態は画面内で保持されますが、再読み込み後の復元は共有機能とともに後続の PR で実装します。

開発サーバーの `#/dnd-trial` には共通編集部品の試運転画面も残しています。採用判断と残る確認事項は [Phase 1 リメイク計画](docs/phase1-remake-plan.md#pr-03-ドラッグ操作ライブラリの試運転と採否) に記録しています。

## 必要な環境

- Node.js 24.21.0（`.tool-versions` に固定）
- npm 11

## 開発

```sh
npm ci
npm run dev
```

Vite が表示する URL を開いてください。画面の経路にはハッシュ形式（`#/chart` など）を使用します。

## 確認コマンド

```sh
npm run check       # 型検査、lint、整形検査、単体テスト、ビルド
npm run test:e2e    # ブラウザーテスト
```

ブラウザーテストの初回実行前に `npx playwright install chromium` で Chromium を用意してください。

## 静的ファイルの生成

```sh
npm run build
npm run preview
```

生成物は `dist/` です。公開先がサブパスの場合は、ビルド時に末尾の `/` を含む `APP_BASE_PATH` を設定します。例: `APP_BASE_PATH=/stat-tuner/ npm run build`。公開先では、そのパスで `index.html` とアセットを配信してください。

共有 URL の復元機能は後続 PR で実装します。公開先の変更時には既存の共有 URL の到達先も確認します。
